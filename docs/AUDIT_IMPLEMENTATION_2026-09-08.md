## Preservation and release boundaries

- Existing target IDs and historical answers remain compatible. New optional fields do not rewrite old midpoint scores into invented answers. Strict stored-plan/draft parsing refuses malformed sources instead of replacing them with defaults.
- Database version 10 retains the existing stores/records and blocks older version-9 app clients from reopening and truncating expanded data. The database gate handles blocked/future-version connections without deleting data. A code rollback to a v9 client is not a data rollback; use a compatible client and verified backup strategy.
- New backups use format 3; historical formats 1/2 remain validated import inputs. Selective reports are separately chosen, readable exports. The app has no new accounts, backend, analytics upload, clinician monitoring or automatic messaging.
- [Qualified clinical/content review](../artifacts/anchor/docs/QUALIFIED_CONTENT_REVIEW_PACKET.md) is **PENDING**. Source checks and software tests do not establish clinical efficacy, bilingual clinical approval or medical-device status.
- Public hosting/deployment is unchanged. No publication is implied by this document. Remote Linux CI, physical installed Android/iOS behavior, Safari printing and a full accessibility assessment remain unverified.

### Defects found and corrected during the final UI audit

- The database gate's extra layout wrapper allowed fixed navigation to cover Quick and Journal save controls; page-height constraints now reach the route wrapper, and normal Save clicks pass.
- Prefilled text/select controls sometimes incorporated their values or all options into accessible names; explicit names now remain stable.
- An actual generated report was clipped after one page; print ancestors now flow over pages and use white margins.
- A long Dutch safety metric overflowed its card at 320 px; the grid stacks at that width and labels wrap.
- Printed goals omitted their direction; abstinence/reduction/harm-reduction/personal direction is now explicit.
- Cancelling Reset failed to return keyboard focus to its opener; explicit focus restoration now passes.
- Settings still described the journey date as an abstinence streak; its NL/EN explanation now describes elapsed journey time.

Independent review of candidate C recorded 14 functional assertions and 12 width checks with no runtime errors, and visually inspected every PDF page. The final artifact adds only the reset-focus fix after C; its full 11-test suite and additional backup test passed. Final screenshots include the action card, the English plan in light mode, and reset confirmation; draft screenshots contain only synthetic examples.
